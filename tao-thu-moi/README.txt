TAO THU MOI - DR.CGF

1) Upload nguyên folder này vào thư mục web.
2) Nếu giữ tên folder "tao-thu-moi" thì URL là: https://drcgf.vn/tao-thu-moi/
3) Nếu muốn đúng URL https://drcgf.vn/taothumoi/ thì đổi tên folder thành: taothumoi
4) File mẫu thư mời là: img/thu-moi.png
   - File hiện tại đã được đưa sẵn vào folder.
   - Nếu thay template mới, nên giữ đúng kích thước 1536x2048 và đúng vị trí lỗ ảnh/tên.
5) Ảnh khách KHÔNG upload lên server. Trình duyệt chỉ đọc tạm trên máy khách và xuất JPG trực tiếp.

Layer khi xuất:
- Trên cùng: tên khách
- Giữa: PNG thư mời
- Dưới cùng: ảnh khách

Chỉnh vị trí mặc định trong tao-thu-moi.js:
HOLE = vùng lỗ ảnh
NAME = vị trí tên
